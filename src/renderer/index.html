App Lock (PIN)

Require a PIN before QuoteCraft opens — a deterrent for anyone with casual access to this computer.

Read this before turning the lock on.

Your data never leaves this device and there is no cloud account to verify you, so a forgotten PIN cannot be recovered by us — by design. If you forget it, the only ways back in are restoring a backup made before the lock was enabled, or deleting the app's data file on this device (which resets everything). Anyone with physical access to this computer could do the same, so treat App Lock as a deterrent, not absolute protection, and pick a PIN you will remember.
